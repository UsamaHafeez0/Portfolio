# Usama Hafeez — Portfolio

Minimalist portfolio site. Next.js (App Router, static export) — no server needed to host.

## Run locally

```bash
npm install
npm run dev        # http://localhost:3000
```

## Build for hosting

```bash
npm run build      # outputs static site to ./out
```

Deploy the `out/` folder anywhere: Vercel, Netlify, GitHub Pages, Cloudflare Pages.

## Structure

- `data/projects.js` — case study content (single source of truth). Edit copy here.
- `data/site.js` — name, email, LinkedIn, **booking URL** (swap the cal.com placeholder), site URL for sitemap/OG.
- `data/experience.js` — experience timeline rows + skills chips. Periods optional.
- `data/posts.js` — blog posts. Blog nav link & index stay hidden while this is empty. Medium imports: set `canonicalUrl`.
- `app/page.jsx` — homepage (hero → work → experience → about → CTA)
- `app/work/[slug]/page.jsx` — case study template
- `app/blog/` — blog index + post template
- `app/globals.css` — design system (colors, type, spacing)
- `app/icon.svg`, `app/sitemap.js`, `app/not-found.jsx` — favicon, sitemap, 404
- `public/images/covers/` — card cover images (currently placeholder SVGs)
- `public/images/` — drop real app screenshots here, then reference them in
  `data/projects.js` under each project's `sections[].images`
  (e.g. `{ src: "/images/tuam-main.jpg", caption: "Home feed" }`) and swap
  `cover` to a real shot when ready.

## Design intent

Low cognitive load: short one-liners, 3-bullet TL;DRs, capability chips instead
of paragraphs, generous whitespace, one accent color, system fonts.

generated by `scripts/gen-preview.mjs` (`node scripts/gen-preview.mjs`).
